    The Galyleo Service API

    The Galyleo Service API

    The Galyleo Service API is an implementation of the Simple Data Transfer Protocol API, with additional methods to permit the publication and sharing of data and tables. It is a standard REST API.

    Base URL

    All methods are formed from the base URL, which is jupyter-hub-url/services/galyleo. So, for example, if the Hub was at https://galyleo-beta.engagelively.com/, the base URL for the Galyleo service is https://galyleo-beta.engagelively.com/services/galyleo. And a request to list tables from this URL would be:

    curl https://galyleo-beta.engagelively.com/services/galyleo/get_table_names

    Supported API Methods

    Route Method Parameters Description SDTP Method
    dashboards/owner/dashboard GET None Return the dashboard owned by owner named dashboard No
    table/owner/table GET None Return the table owned by owner named table No
    publish_data POST -table, a table in SDML format
    -name, which must end in .sdml.
    -Optionally, share_list, the list of users with access to the table    		 Publish the table to tables/owner/name No
    publish POST -dashboard, a dashboard in Galyleo format
    -name, which must end in .gd.json.
    -Optionally, share_list, the list of users with access to the dashboard    		 Publish the dashboard as dashboards/owner/name No
    get_table_names GET None Get the tables (as a list of URLs) accessible by this user Yes
    get_table_schemas GET None Get the schemas of tables accessible by this user Yes
    get_table_schema GET table, the name of the table to get the schema for. Get the schema of the table Yes
    get_range_spec GET -table, the name of the table
    -column, the name of the column    		 Get the max and min of the column, as a list Yes
    get_all_values GET - table, the name of the table,
    -column, the name of the column    		 Get the distinct values of the column, as a JSON list Yes
    get_column GET -table, the name of the table
    - column, the name of the column    		 Get the column, as a JSON list Yes
    get_filtered_rows POST table, the name of the table
    - Optional: columns, a list of columns to get,
    - Optional: filter_spec, a filter in SDQL format    		 A list of rows which match the filter, or all rows if the filter is not present Yes

    Authentication

    Authentication is by Bearer Token; see the Authentication section below. All methods except publish_data and publish permit anonymous access, but only tables and dashboards shared with the public will be available to the user

    Successful Returns

    Data is always returned as a JSON list of values, for easy parsing.

    Errors

    Standard errors (400, 401, 403) are returned with an explanatory error message.
